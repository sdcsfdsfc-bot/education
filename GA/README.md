# 숲의 나방 · 무늬 진화 실험실

HTML, CSS, JavaScript만으로 실행되는 GitHub Pages용 교육 사이트입니다. `index.html`은 알고리즘 배경·원리와 정체 현상을 소개하며, `learn.html`에서 기존 단계별 튜토리얼과 직접 실험을 진행합니다. Python, Tkinter, 빌드 과정은 필요하지 않습니다.

## 점수 정체와 중지 기준

`stagnation.js`의 규칙을 소개 페이지의 가상 기록과 실제 실험이 함께 사용합니다. 마지막으로 갱신을 인정한 최고 점수보다 0.005%p를 초과해 높아져야 정체 횟수가 0으로 돌아갑니다. 그런 갱신이 없는 세대가 40번 연속되면 자동·수동 진행을 멈춥니다. 전체 실행 세대 수가 40으로 제한되는 것은 아닙니다. 이 종료는 추가 탐색의 정체를 기준으로 하며 전역 최적해 도달을 증명하지 않습니다.

## 학습 흐름

1. **문제와 유전자:** 목표, 숫자 유전자 12개, 나무와 나방에 공통으로 쓰는 무늬 생성 원리를 세 소단계로 봅니다.
2. **적합도 평가:** 나방 날개의 색을 같은 위치에 그려진 나무 무늬와 비교합니다.
3. **부모 선택:** 점수를 선택 확률로 바꾸고 난수로 부모를 뽑는 두 소단계입니다.
4. **유전자 교차:** 색 유전자와 무늬 유전자의 계산을 두 소단계로 봅니다.
5. **돌연변이:** 바뀐 숫자와 무늬를 전후로 비교합니다.
6. **세대 교체:** 자손 11마리와 보존한 최고 나방 한 마리로 새 집단을 만듭니다.
7. **내가 직접 실험하기:** 나방 24마리로 한 번에 한 세대를 진행하거나 자동으로 진화시킵니다. 첫 세대부터 현재까지 최고 점수와 집단 평균을 넓은 그래프로 표시하고, 변화 폭에 맞게 세로축을 조절합니다. 새 최고 점수가 나오면 상단 카드에 갱신 폭을 표시합니다. 최고 점수 갱신 없이 40세대가 연속되면 자동·수동 진행을 멈춥니다. 사용자가 고른 유전자당 변이 확률 0~5%를 그대로 적용합니다. 최고 점수가 4세대 이상 정체되면 변이 확률은 유지하고 변이 폭만 조금 넓힙니다. 최고 나방 한 마리는 항상 보존하며, 개선을 보장하지는 않습니다. 나무 색·무늬를 바꾸면 기존 나방의 유전자는 유지하고 새 환경에서 점수와 세대 그래프를 다시 시작합니다.

## 유전자와 무늬

한 나방은 숫자 유전자 12개를 가집니다.

| 유전자 | 수 | 역할 |
| --- | ---: | --- |
| 바탕색 L*a*b* | 3 | 날개의 바탕색 |
| 무늬색 L*a*b* | 3 | 날개에 나타나는 무늬색 |
| 무늬 종류 | 1 | 미리 계산한 반응·확산 무늬 사이의 혼합 |
| 무늬 크기 | 1 | 흑백 무늬의 확대·축소 |
| 무늬 기준값 | 1 | 흑백 무늬를 두 색 영역으로 나누는 기준 |
| 줄무늬 늘이기 | 1 | 무늬의 세로 비율 |
| 경계 강조 | 1 | 두 색 영역 경계의 밝기 변화 |
| 작은 점 밀도 | 1 | 미세한 점을 추가하는 정도 |

완성된 날개 이미지를 복사하는 대신, 이 숫자로 무늬를 매번 다시 그립니다. 각 자손은 부모를 새로 뽑고, 숫자마다 임의의 혼합 비율을 적용해 가중평균을 만듭니다. 변이 때는 선택된 숫자에 작은 값을 더하거나 빼며, 드물게 새 값으로 바꿔 다양성을 남깁니다. 가장 높은 점수의 나방 한 마리는 그대로 보존합니다. 위장 점수는 평균 RGB 차이 `d`에서 `100 × exp(-d / 28)`로 계산하여 초기 점수가 상한에 몰리지 않게 했습니다.

나무껍질도 같은 반응·확산 무늬 배열과 12개 숫자로 만듭니다. 흑백 무늬를 기준값으로 나누고 나무의 두 색을 입힙니다. 나무의 숫자는 환경을 만들기 위한 값이며 진화하거나 나방에게 유전되지 않습니다. 나무 무늬를 바꾸면 화면에 그린 새 무늬를 위장 점수 계산에도 그대로 사용합니다.

이 구현은 [CamoEvo 논문](https://academic.oup.com/evolut/article/76/5/870/6881792)의 반응·확산 무늬, L*a*b* 색 좌표, 수치 유전자의 교차·변이 개념에서 영감을 받은 **교육용 단순화 모형**입니다. CamoEvo의 원본 코드나 실험 결과를 재현한 것은 아닙니다. 무늬 종류는 네 개의 미리 계산한 Gray–Scott 배열 사이에서 보간합니다. 위장 점수는 날개 표본의 RGB 값과 나무껍질 표본의 평균 차이를 교육용 함수로 변환합니다. 사람의 발견이나 새의 공격을 실제로 시뮬레이션하지 않습니다. 최고 점수가 전역 최적해라는 보장도 없습니다.

## GitHub Pages 게시

1. 이 폴더 전체를 GitHub 저장소의 기본 브랜치 루트에 올립니다. `.gitignore`는 로컬 원본 `1.py`를 제외합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 기본 브랜치와 **/(root)**를 선택해 저장합니다.
4. Pages 화면에 표시되는 주소에서 사이트를 엽니다.
