index.html, learn.html, overview.js, engine.js, app.js, lesson-video.js, media와

학습 화면으로 돌아가면 실제 탐색이 일시정지되며 기록과 설정은 유지됩니다.
시뮬레이션 화면으로 이동하면 학습 영상이 일시정지됩니다.

1. 탐색 재생: 반복당 여러 개미의 이동을 보여줍니다. 같은 버튼으로 일시정지합니다.
2. 상단 학습 화면: 이전 단계 / 다음 단계 버튼으로 여섯 설명을 한 장씩 넘깁니다.
   단계 번호 1~6을 누르면 해당 설명으로 바로 이동합니다.
   설명 영역에서 ← / → 또는 Page Up / Page Down 키로도 이동할 수 있습니다.
   마지막 설명의 '시뮬레이션으로'를 누르면 두 번째 탭의 탐색 조작 영역으로 이동합니다.
   설명만 넘겨보는 동안 실제 도로망과 탐색 기록은 유지됩니다.
   실제 탐색을 진행하면 학습 화면도 해당 단계 설명으로 전환됩니다.
   '탐색 한 단계'는 실제 탐색 → 시간 평가 → 증발 → 보강 → 반복·비교를 진행합니다.
   화면 상단에 각 단계의 설명과 작은 도로망 그림이 있습니다.
   1~5단계 그림과 6단계 영상은 같은 병원·사고 현장과 네 가지 후보 길을 사용합니다.
   단계에 따라 개미의 위치, 시간 평가, 페로몬의 양과 도로 폭이 달라집니다.
   그림의 시간·확률·페로몬은 별도 학습 예시이며 실제 지도 계산값과는 구분됩니다.
   2단계에는 정규화된 선택 확률식과 A~D의 가중치 계산표가 있습니다.
   4단계에는 증발 후의 확률식과 증발 전후 τ·가중치·확률 비교표가 있습니다.
   모든 후보 페로몬을 같은 양의 비율로 줄이고 시간과 후보를 유지하면
   공통 계수가 약분되어 증발만으로 선택 확률은 달라지지 않습니다.
   6단계에는 약 30초의 실제 WebM 학습 영상이 첨부되어 있습니다.
   개미 12마리가 완주할 때마다 경로별 누적 완주 횟수, τ, 다음 선택 확률을 표시합니다.
   학습 영상 조건: α=1, β=2, ρ=0.2, Q=10, 초기 τ=1, 반복당 개미 1마리.
   한 마리 완주 시 모든 τ를 0.8배 하고 완주 경로의 도로에 10/T를 더합니다.
   경로 시간은 A 12분, B 9분, C 11분, D 15분이며 출발 도로 시간은 각각 T/2입니다.
   영상 재생·일시정지, 시간 막대 이동, 한 마리 완주, 처음부터, 배속 변경이 가능합니다.
   영상 아래 표도 현재 영상 위치에 맞춰 같은 수치를 보여줍니다.
   영상 저장 링크로 WebM 파일을 저장할 수 있습니다.
   6단계에서 나가면 영상이 일시정지됩니다. 영상을 재생하면 실제 도로망 탐색이 일시정지됩니다.
   media 폴더의 영상·포스터·수치 데이터는 오프라인 실행에도 필요합니다.
3. 지도 도로 또는 드롭다운 선택: 길이, 속도, 신호 대기, 혼잡 배수, 통제 변경.
4. 중앙역 우회로 혼잡 예시: 모든 도로를 초기 예시로 복원한 뒤
   중앙역–과학관 연결 도로 X03에 혼잡을 적용합니다.
   중앙역–시장 직접 도로는 삭제되었으며 B는 병원–중앙역–과학관–사고 현장입니다.
   A 12분, B 17분, C 11분이 되어 C가 최소시간 경로가 됩니다.
5. 초기화: 도로, 탐색 설정, 비교와 기록을 모두 처음으로 되돌립니다.
6. 기록의 반복/개미 버튼: 각 교차로에서 실제 사용한 선택 확률을 확인합니다.
   갈림길 선택 확률은 지도 바로 아래에서 도로별 확률, 목적 장소, 시간을 비교합니다.
   기존 기준 경로 A~F의 카드 목록은 표시하지 않습니다.

시간 단위: 분 = km / (km/h) × 60 + 신호 대기 초 / 60.
유효속도 = 예상 주행속도 / 혼잡 배수.
재생 배속은 애니메이션에만 적용하며 계산 시간에는 영향이 없습니다.
개미 탐색 애니메이션은 기본 1배속에서 9초 동안 진행됩니다.
더 천천히 관찰하려면 재생 배속을 0.5배 또는 0.25배로 바꾸세요.
도로 중앙은 투명하고 테두리만 표시됩니다. 테두리 색은 혼잡도,
도로 폭은 페로몬, 금색은 선택 도로, 파란색은 ACO 최선 경로를 나타냅니다.
도로 중앙의 보라색 점은 페로몬의 밀도·크기·진하기를 나타냅니다.
노란 원은 이동하는 개미입니다.
'페로몬 수치(τ) 표시'로 도로별 현재 값을 켜고 끌 수 있습니다.
선택한 도로는 수치 표시를 꺼도 시간과 τ가 항상 나타납니다.
지도 위에는 현재 단계와 최소·최대 페로몬이 표시됩니다.
추첨 기록의 '당시 τ'는 선택 당시 값이며, 지도에는 현재 남은 값이 표시됩니다.
도로/ACO 설정 변경은 탐색을 중지하고 페로몬 1과 빈 기록으로 새로 시작합니다.
ACO는 무작위 알고리즘이므로 실행마다 탐색 결과가 다를 수 있습니다.
이 도로망은 14개 장소와 37개 도로가 연결된 교육용 양방향 그래프입니다.
기준 경로 A~F 외에도 X01~X20의 연결 도로로 중간 장소 사이를 이동할 수 있습니다.
개미는 여러 기준 경로의 일부와 연결 도로를 섞어서 탐색합니다.
이러한 결과는 기준 경로 A~F와 구분하여 '조합 경로'로 표시합니다.
지도에서 장소 원이 없는 단순한 선의 교차점은 서로 연결되지 않습니다.
장소 배치와 선의 길이는 가상이며 계산에 쓰는 거리와 비례하지 않습니다.
복잡한 지도에서는 도로를 선택해 해당 시간을 확인하고,
'모든 도로의 시간 표시'를 켜면 모든 도로의 시간을 볼 수 있습니다.

E 도서관·체육관 4.6 km / 14분, F 물류센터·남문 5.0 km / 16분.
모든 도로는 지도에서 선택하여 편집·혼잡 설정·통제가 가능합니다.
